# C&I Simulator

https://avtorhanov.github.io/C-I-simulator/

Интерактивный тренажёр приводов 
Каждый узел — отдельный модуль в `units/`. Первый узел — отсечной клапан ПАЗ; дальше добавляются регулирующий, кулисный, поршневой и другие.

## Узлы

| Узел | Статус |
|---|---|
| [Отсечной клапан ПАЗ](units/esd-ball-rp/) — шаровой кран, реечный привод с пружинным возвратом | готов, v0.3 |
| [Регулирующий клапан](units/ctl-globe-diaph/) — седельный, мембранный привод | бета, v0.1 |

## Узел №1: отсечной клапан ПАЗ

Узел отсечного шарового крана с пневмоприводом.

- **Схема узла целиком:** ФР → тройник → позиционер → SOV-РСУ → SOV-ПАЗ → бустер → реечный привод → вал → шаровой кран, сверху БКВ. Видно давление в линиях, движение воздуха и поворот шара.
- **Разрез каждой детали:** тап по узлу показывает его устройство в работе. Кнопка ▶ проигрывает срабатывание по фазам.
- **Пошаговые сценарии:** открытие по РСУ, закрытие по ПАЗ, закрытие по РСУ, частичный ход (PST).
- **Управление как с АРМ:** ОТКРЫТЬ / ЗАКРЫТЬ (РСУ), срабатывание ПАЗ, PST. Концевики ЗАКР / ОТКР / №3, время хода, контроль рассогласования.
- **15 неисправностей:** признаки, возможные причины, проверка и поиск, устранение, место на схеме.
- **Справка** по общей картине и по каждой детали.
- Полноэкранный режим, 4 темы, единицы бар / кгс/см² / кПа / МПа.

## Устройство репозитория

```
index.html            каталог узлов
core/                 общее: sim-core.js (физика: петля 4–20, пневматика, позиционер), theme.css (темы)
units/index.json      реестр узлов
units/<id>/           узел: index.html, unit.css, sim.js (модель), scene.js (схема и UI), details.js (разрезы)
test/                 юнит-тесты моделей (node --test)
e2e/                  проверки на профиле телефона (Playwright, CPU×6)
tools/                сборка узла в один HTML
sw.js, manifest       офлайн и установка
```

**Новый узел:** папка `units/<id>/` + строка в `units/index.json` + файлы в `sw.js` + тест модели в `test/`. Ядро не меняется.

## Разработка

```
npm test              юнит-тесты моделей
npm run e2e           проверки на экране телефона (нужны python3 и playwright)
npm run serve         локальный сервер: http://localhost:8080
npm run build         сборка узлов в dist/*.html
```

## Важно

Учебная модель, параметры типовые. Устройство деталей показано обобщённо, без привязки к конкретному производителю. Не заменяет РЭ производителя, проектную документацию и регламенты объекта.
