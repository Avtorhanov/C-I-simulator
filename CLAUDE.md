# C&I Simulator — правила для работы в репозитории

- Язык интерфейса и документации: русский. Пользователь на телефоне: mobile-first 360/390/412/430 px.
- Стек: vanilla JS без сборщика, PWA (sw.js). Без внешних библиотек.
- Модель (sim) отдельно от UI, детерминированная, шаг 1 мс, с юнит-тестами в test/.
- Каждый узел — units/<id>/; общее — только в core/. Узлы не зависят друг от друга.
- Детали только типовые: без логотипов, брендов и копии интерфейса производителя.
- В каждом узле пометка «не заменяет РЭ производителя». Процедуры ремонта и настройки не выдумывать — сверять с экспертом.
- Перед коммитом: npm test и npm run e2e (3 прогона из 3), без горизонтальной прокрутки, консоль чистая.
- При изменении файлов узла — поднять VERSION в sw.js и version в units/index.json.
